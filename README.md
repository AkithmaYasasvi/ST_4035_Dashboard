# Binary Logistic Regression Dashboard

A simple interactive dashboard developed for the ST4035 assignment using HTML, CSS, and JavaScript.

This project explains:
- Link functions in logistic regression
- Class balancing techniques
- Evaluation metrics for imbalanced datasets

## Files
- `index.html` – Main webpage
- `styles.css` – Styling
- `script.js` – Functionality

## How to View
Open `index.html` in a web browser.
