Theoretical Insights & Methodology

Link Functions
Link functions convert a linear score into a probability (0–1).
• Logit: Symmetric S-curve based on log-odds.
• Probit: Symmetric S-curve based on normal distribution.
• Cloglog: Skewed curve; effective for rare events.
Class Balancing
When one class is rare, models ignore it. Balancing helps:
• Oversampling: Copying rare-class records.
• Undersampling: Removing common-class records.
• SMOTE: Synthetically creating new rare-class examples.
Evaluation Metrics
Accuracy alone is misleading with imbalanced data. Use:
• Sensitivity: How many actual high-risk patients were caught?
• Specificity: How many healthy patients were correctly cleared?
• AUC: Overall score 0.5–1.0 (higher = better model, regardless of threshold).
